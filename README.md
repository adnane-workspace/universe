# Gestion des absences — application mobile

Application React Native créée avec Expo, TypeScript et Expo Router.

## Démarrer

```powershell
pnpm start
```

Dans le terminal Expo, appuyez sur `w` pour ouvrir la version web ou scannez le QR code avec Expo Go.

## Écrans disponibles

- **Enseignant** : aperçu des absences, prochains cours et étudiants à suivre. Le bouton d’appel illustre l’enregistrement d’une séance.
- **Étudiant** : résumé de présence, absences et dépôt simulé d’un justificatif.
- **Administration** : indicateurs de l’établissement et raccourcis de gestion.

Les données affichées sont provisoires : aucune API ni authentification n’est encore configurée.
